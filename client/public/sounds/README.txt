# Thư mục chứa nhạc chuông tùy chỉnh (Custom Ringtones) cho NomNa Call
Thả các file âm thanh vào đây nếu bạn muốn phát bài hát mình thích:
- `ringtone.mp3`: Nhạc chuông khi có người gọi đến (Incoming Call).
- `calling.mp3`: Nhạc chờ khi bạn bấm gọi đi (Outgoing Call).
- `call-end.mp3`: Âm thanh khi dập máy / kết thúc cuộc gọi (Call End).

*Ghi chú*: Nếu chưa có file MP3, hệ thống sẽ tự động dùng âm thanh điện tử tổng hợp (Web Audio API) dự phòng để luôn luôn có tiếng chuông.
